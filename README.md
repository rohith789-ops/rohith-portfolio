# Rohith's Software Engineer Portfolio

A responsive portfolio with separate pages for the home page, About, Skills, Projects, Experience, Education, and Contact.

## Run locally

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Open the **Local** URL printed by Vite (usually `http://localhost:5173/`).

## Publish to GitHub Pages

1. Create a public repository, e.g. `portfolio`.
2. Run `npm run build`.
3. Publish the contents of the generated `dist` folder using GitHub Pages.
4. In repository Settings > Pages, select the branch and folder containing those files.
5. Wait for GitHub to publish the site at `https://YOUR-USERNAME.github.io/portfolio/`.

## Customize before sharing

- Add real project repository/demo URLs to each project card when available.
- Confirm all resume facts and certification names/dates.
- Replace the PDF when your resume is updated.
- Consider adding project screenshots, architecture diagrams and a favicon.

The website intentionally does not claim unverified performance metrics, project demos or proficiency percentages.
